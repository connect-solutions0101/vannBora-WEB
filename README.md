# 🌐 Vann Bora - Web

Este repositório contém o **frontend web** do projeto **Vann Bora**, desenvolvido com **React** e **Vite**. O projeto foi realizado como parte da formação na **SPTECH** durante o terceiro e quarto semestre.

## 🛠️ Tecnologias Utilizadas

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS)
- HTML5

## 📁 Estrutura do Projeto

- `src/`: Código-fonte principal da aplicação
- `index.html`: Ponto de entrada da aplicação
- `.env`: Variáveis de ambiente
- `vite.config.js`: Configuração do Vite
- `.github/workflows/`: CI/CD com GitHub Actions

## 🚀 Como Executar Localmente

### 1. Pré-requisitos

- Node.js (versão 18+ recomendada)
- NPM ou Yarn

### 2. Clonar o Repositório

```bash
git clone https://github.com/seu-usuario/vann-bora-web.git
cd vann-bora-web
```
### 3. Instalar Dependências

**npm install**
ou
**yarn install**

### 4. Rodar o Projeto

**npm run dev**
ou
**yarn dev**

O aplicativo estará disponível em: http://localhost:5173
# 📌 Observações

    - Certifique-se de configurar corretamente o arquivo .env caso utilize variáveis sensíveis.

    - Este projeto está configurado para deploy na Azure Static Web Apps.
